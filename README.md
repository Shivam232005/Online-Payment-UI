# Mobile Payment Checkout UI

This is a mobile-first HTML/CSS checkout UI featuring a sleek, three-tiered layout anchored by a vibrant purple gradient and an elevated price summary card. The crisp white bottom section ensures high readability for the alternative payment buttons, structured credit card form, and a prominent "Pay Now" call-to-action.

## Features
- **Mobile-First Layout:** A fixed-width (350px) container optimized for mobile device screens.
- **Modern Aesthetics:** Utilizes CSS linear gradients and subtle box-shadows to create an elevated, floating card effect.
- **Clean Form Structure:** Includes neatly organized input fields for Card Number, Expiry Date, CVC, and Card Holder Name.
- **Zero Dependencies:** Built entirely with vanilla HTML5 and CSS3—no external frameworks, libraries, or scripts required.

## File Structure
- `index.html` — Contains the structural layout, navigation, and payment form elements.
- `style.css` — Contains all the styling, custom gradients, layout positioning, and typography rules.
